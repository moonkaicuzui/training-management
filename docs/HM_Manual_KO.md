## 3. 설정 페이지

**URL**: `/equipment/humidity-monitor/settings`

**35개 구역**의 마스터 데이터를 관리하는 페이지입니다.

### 가능한 작업
| 작업 | 방법 |
|------|------|
| 전체 구역 조회 | 설정 페이지를 열면 전체 목록 확인 |
| 구역 추가 | "구역 추가" 버튼 클릭 → 구역명, 빌딩, 목표수량(T.O) 입력 |
| 구역 수정 | 해당 구역의 편집 아이콘 클릭 → 내용 수정 → 저장 |
| 구역 삭제 | 해당 구역의 삭제 아이콘 클릭 → 확인 |
| 초기 데이터 등록 | "초기 데이터 등록" 버튼 클릭 (최초 1회만) — 35개 구역 일괄 등록 |

### 구역 정보
각 구역에는 다음 정보가 포함됩니다:
- **구역명**: 해당 영역의 이름 (예: "A-1F Cutting")
- **빌딩**: 소속 빌딩 (A, B, C, D, E)
- **목표수량 (T.O)**: 해당 구역에 있어야 하는 장치 수

## 4. 점검 입력 페이지 (핵심 페이지)

**URL**: `/equipment/humidity-monitor`

**가장 중요한 페이지**입니다. 이 페이지에서 점검 결과를 입력합니다.

### Step 1: 점검 일자 선택
- 날짜 입력 필드를 클릭합니다
- 점검을 실시한 날짜를 선택합니다

### Step 2: 검사자 이름 입력
- 점검을 실시한 사람의 이름을 입력합니다

### Step 3: 구역별 결과 입력

**35개 구역**이 테이블로 표시됩니다. 각 구역별로:

| 컬럼 | 의미 | 입력 방법 |
|------|------|----------|
| **구역** | 구역명 | (자동 입력) |
| **T.O** | 목표수량 | (설정에서 자동 입력) |
| **OK** | 정상 작동 장치 수 | 기본값 = T.O. 다를 경우에만 수정 |
| **NO OK** | 비정상 장치 수 | 기본값 = 0. 비정상 장치가 있으면 수량 입력 |
| **보유합계** | OK + NO OK | (자동 계산) |
| **부족(Missing)** | 보유합계 - T.O | (자동 계산) 장치가 부족하면 음수 표시 |
| **비고(Remark)** | 문제에 대한 메모 | NO OK > 0 또는 부족 시 **필수 입력** |

### 빠른 입력 방법
- **모두 정상인 경우**: 아무것도 수정할 필요 없습니다. 기본값이 OK = T.O, NO OK = 0입니다
- **문제가 있는 경우**: 문제가 있는 구역만 수정하면 됩니다
- **비고 필수**: 구역에 NO OK > 0 또는 부족한 장치가 있으면 반드시 비고를 작성해야 합니다

### Step 4: 저장
- 하단의 **"일괄 저장"** 버튼을 클릭합니다
- 35개 구역이 한번에 저장됩니다

### 기존 데이터가 있는 경우
- 이미 데이터가 있는 날짜를 선택하면 기존 데이터가 로드됩니다
- 수정 후 다시 저장할 수 있습니다 (수정 모드)

## 5. 대시보드

**URL**: `/equipment/humidity-monitor/dashboard`

대시보드에서 현재 현황과 추이를 확인할 수 있습니다.

### KPI 카드 (상단)
| 카드 | 표시 내용 |
|------|----------|
| **총 장치** | 전체 모니터링 장치 수 (38대) |
| **정상(OK)** | 정상 작동 중인 장치 수 |
| **비정상(NO OK)** | 비정상 장치 수 |
| **부족(Missing)** | 구역에서 부족한 장치 수 |

### 정상률 추이 차트
- **최근 12회 점검**의 정상률(%)을 보여줍니다
- 상황이 개선되고 있는지 악화되고 있는지 파악할 수 있습니다

### 빌딩별 비교 테이블
- 빌딩별(**A, B, C, D, E**) 현황을 비교합니다
- 각 빌딩의 정상 수, 비정상 수, 정상률을 표시합니다

### 반복 이슈 구역
- **3회 이상 연속** 비정상이 발생한 구역을 표시합니다
- 이 구역들은 특별한 관심이 필요합니다

### 점검 이력 테이블
- 과거 모든 점검 기록을 표시합니다
- 기록을 클릭하면 상세 내용을 확인할 수 있습니다
